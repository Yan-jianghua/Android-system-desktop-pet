# 球球 1.5 复查结果

此前 1.4.3 核对报告中的缺口已在本版处理。本版为纯文字气泡，不再播放声音。

| 复查项 | 结果 |
| --- | --- |
| 应用首页自动待机 | 与悬浮窗共用 IdleMotion，约 7–13 秒自动随机换动作，移除手动待机按钮；生命周期暂停和恢复会管理定时器。 |
| 亮屏及解锁问候 | 注册 SCREEN_ON、SCREEN_OFF 和 USER_PRESENT；亮屏启动文字问候，约 2.2 秒后接第二句，随后立即解锁时避免重复问候。系统锁屏是否允许显示悬浮窗尚需真机确认。 |
| 删除语音 | Android TTS 初始化、播放、关闭和服务查询均已删除；首页语音设置、预览语音按钮及 speechSynthesis 播放均已删除。 |
| 动作期间拖动 | 任意动作可拖动整个悬浮窗，拖动显示走/跑；基础照料状态和计时保留，松手恢复。实际预览控制器的忙碌拖动测试通过。 |
| 菜单开着时排泄 | 排泄调度不再被菜单或拖动阻止。实际浏览器确认菜单打开时开始尿尿。 |
| 进食或铲屎时排泄 | 排泄优先，暂存未完成照料动作的时间和动画进度，排泄后继续；同时到点的尿/便依次进行。实际浏览器确认猫条进食被尿尿打断后继续。 |
| 喂食反应及十秒冷却 | 回调只触发一次；猫条开心和指定文字不丢失，巧克力嫌弃与指定文字保留。冷却继续按真实时间保存。进食累计动作时长五秒，排泄暂停时间另计。 |
| 七秒清理及计数 | 清理累计动作时长七秒；被排泄打断后恢复剩余时间。清理完成时读取实际废物数，报告包含期间新增的废物，再清空。进程中断仍不清空。 |
| 记忆和日期问答 | 未改变持久化键。关闭/重开、去重、喂食数量边界、农历生日、节日及固定家庭回复测试全部通过。 |

实际运行通过的检查：MemoryCheck、CalendarCheck、ActionCheck、preview-check.cjs、interaction-check.cjs、JavaScript 语法、Android assembleDebug、lintDebug（0 错误 / 5 警告）、APK v2 签名及包版本校验。打包的 HTML 和 JS 与最终源码一致，DEX 无 Android TTS 引用。预览无控制台错误。

版本：1.5-text / versionCode 9。安装包为 dist/球球桌面宠物-新版.apk，直接覆盖安装可保留本地记忆。

仍未真机验收：悬浮窗权限、品牌手机锁屏/亮屏广播、实际拖动手感、后台长时间运行。手机熄屏、应用被系统暂停或用户关闭宠物时无法承诺屏幕动作准点展示；到期事件保留并在恢复后按顺序补播。后台服务运行、屏幕可见时，调度每 250 毫秒检查一次。
