# 2.3.4 AI 需求补全验证记录

版本：`2.3.4-ai-completion` / versionCode `48`

## 本次补齐

- 每次正常回答后提供“答对了”和“教它改正”入口；纠错内容会更新对应问题的教学规则，并重新生成一次回答。AI 未配置或请求失败时，仍按主人给出的正确内容回答。
- 同主题记忆发生冲突时，明确提供“保留旧记忆”“替换为新内容”“取消”三种选择；偏好、厌恶、姓名、生日及父母偏好按主题分别判断。
- AI 返回空内容、格式无法解析，或 DNS/连接在发送前失败时，最多自动安全重试一次。读取超时、服务端错误和额度错误不自动重试，避免服务已受理时重复扣费。
- 新增请求与回答使用相同请求 ID。重新打开聊天记录时，将没有对应回答的已提交请求标为“应用中断”，显示未自动重发状态，用户可以自行重新发送。

## 尚需设备验收

- 当前环境没有用户配置的 API Key，也没有连接安卓真机；实际服务连续十轮聊天、自动重试服务行为、纠错后的接口回复，以及 Android 8.0 与新版本设备上的进程回收恢复仍需真机确认。
- 自动重试仅用于客户端明确可重试的空/格式错误响应和连接前失败；不能保证第三方服务的账单幂等性，因此服务端错误、读取超时和额度错误不会自动重发。
