# 球球安卓桌面宠物 · 1.10 五秒动作版

最新安装包：dist/球球桌面宠物-1.15-贴边探头.apk。Android 8.0 以上，首次打开允许“显示在其他应用上层”，点击“让球球出门”。直接覆盖安装以保留记录。全部回复使用文字气泡，不播放声音。部分手机需要在系统设置中允许此应用后台运行。

## 本次更新

- 输入框缩为 136×32dp、12sp 字号，位于脚底下方约 3dp；返回和发送按钮并排放置。气泡尾端靠近猫的可见轮廓，按长短回复动态测量，避免透明画布边距造成大空隙。球球尺寸保持 156dp。
- 13 套动作统一每周期 5 秒、60 个播放帧。原有每套 24 张关键画面保留，用双向运动向量驱动网格变形补间；不是 144 张独立绘制的原画，也不是 144Hz 屏幕刷新率。60 帧 / 5 秒 = 每秒 57.6 个动作姿态，实际显示受设备性能影响。
- 舔毛、趴着摇尾巴、坐着左右看，每套完整播放三个周期（15 秒）后随机换另一套。菜单、拖动、业务动作和隐藏时暂停待机累计计时。
- 进食、开心、嫌弃、排泄、摸摸反应统一五秒；铲屎保留原要求的七秒总操作时间，铲子和小猫动作按五秒循环。
- 安卓和电脑预览共享补间数据；预览的 motion-review.html 支持逐帧查看 1–60 帧。版本号 1.14-rest30，versionCode 16。
- 验证详情见 checks/1.10-验证记录.md。没有连接安卓真机，手机上的帧率和键盘布局尚未实测。

## 1.6 历史更新记录（当前行为以上述 1.10 为准）

- 新增「陪球球玩」：摸摸会眯眼、飘出小爱心；每 30 秒可增加 2 点亲密度，最高 100，重复摸摸仍有动作。每日悄悄话每天首次增加 3 点，今日心情、相伴天数和称号随进度显示。记录与猫砂盆独立保存。
- 重新生成基础、进食、如厕和嫌弃素材，按同一待机形象统一面部与长毛质感，强化胸前长毛、腹部毛和蓬松尾巴；如厕两帧保持蹲姿。
- 普通动作帧之间约 95ms 过渡，不同动作约 170ms 过渡；加入幅度很轻的呼吸。安卓改用帧同步刷新、共享图集缓存和复用绘制缓冲，去掉每帧重建铲屎遮罩。预览减少重复文字刷新。
- 更新浅奶油与鼠尾草绿界面、圆角菜单、按钮和陪伴状态。语音仍完全关闭，只用文字气泡。
- 旧版 APK 和图集保留在 dist/旧版备份 与 model/animation-backups/1.5。请覆盖安装，不要先卸载，以保留猫砂盆与喂食记录。

## 形象

按用户的球球照片生成自己的白色银渐层长毛猫：圆脸、深色大眼睛、蓬松毛发。参考录屏的写实质感，未复用现用 Codex 宠物的图集。没有额头卷发器。当前使用透明帧动画与尾巴分层连续摆动，不依赖实时 3D；旧三维模型试作和旧图集已归档在 model，未打包。

新版素材使用内置 imagegen 生成并保存到 app/src/main/assets/pet-sprites：qiuqiu-own.png（基础动作）、qiuqiu-care.png（进食）、qiuqiu-disgust-v3.png（新版嫌弃）、qiuqiu-toilet.png（排泄）、care-props.png（猫砂盆/手与铲/尿团/便便）。最终生成提示及来源见 model/1.6-美术素材记录.json，实际取帧坐标见 own-atlas.json。基础动作四帧、进食两帧、排泄两种姿势；趴卧尾巴连续摆动。图集已按实际透明间隙修正取帧边界。

历史版本 1.4.1 以原版素材为基础，所有动作的颈部毛领仅作极轻微收窄，下巴、颈部到肩膀保持宽而平滑的毛发过渡，避免明显凹口、束腰式脖子和深色颈沟；保留原版脸型、眼睛和蓬松长毛。嫌弃动作使用轻微压耳、偏头躲开、短暂吐舌、闭嘴恢复四个完整姿势，总长 2.8 秒，吐舌仅停留 0.28 秒，当时使用单帧表情绘制；1.6 对完整姿势增加了短过渡。手机与电脑预览使用相同时间点；仍在吃完巧克力后触发并说“狗屎东西”，喂食冷却仍为十秒。原版及上一版素材保留在 model/animation-backups 中便于对比。

## 原始要求对应实现

1. 应用启动、亮屏及解锁：按手机小时用气泡问早上/下午/晚上好，主人；约 2.2 秒后接“请尽情吩咐球球，主人”。同次亮屏随后立即解锁不重复打断问候；锁屏系统遮挡悬浮窗时可在解锁后显示。所有台词都显示在暖白色圆角气泡内，下方小尾巴指向球球；长句自动换行，拖动时气泡跟随球球。已删除语音引擎、语音设置和预览语音按钮。
2. 无需点击，待机每套播放三个五秒周期后（累计 15 秒）自动随机切换舔毛、低身趴卧、坐着左右看；下一次动作不会与当前动作重复。应用首页、悬浮窗和电脑预览均自动待机，没有三个手动待机按钮。趴卧身体低、前爪伸出，尾巴竖起左右缓摆，尾尖带延迟。喂食、排泄、铲屎、拖动及菜单互动期间暂停随机切换，结束后自动恢复。
3. 任意动作期间都可以拖动悬浮窗，拖动时显示走路，特别快才跑；松手恢复尚未结束的当前动作。进食、清理和排泄计时不会因拖动丢失。速度超过 2200dp/秒且持续 60ms 才跑；走和跑为不同图集。
4. 两小时尿一次，每次一个尿团；六小时便便一次。窗口喂食 0–1 次一块、2–3 次两块、4 次及以上三块。前台宠物运行且屏幕可见时，到点优先排泄，不等待菜单关闭；进食、反应或铲屎暂存已播放进度，排泄后继续剩余时间。尿和便同时到点时按时间顺序播放。排泄在猫砂盆内，完成动画才保存数量；进程中断后重新播放，不重复计数。熄屏或系统暂停应用期间的事件在恢复时补播。
5. 点击显示“请尽情吩咐球球，主人”和喂食、铲屎、对话；菜单显示现有便便和尿团数量。猫砂盆图像仅在小便、大便和七秒铲屎动作期间出现，完成后立刻隐藏；待机、拖动、喂食、对话和清理结果弹窗均不显示猫砂盆。
6. 猫粮、猫条、巧克力均立即开始对应进食动作，动作累计五秒，十秒冷却。被排泄插入时进食进度暂存，排泄后继续；十秒冷却按真实时间保存。猫条后开心并用气泡回复“主人你真好”；巧克力后嫌弃并回复“狗屎东西”。巧克力是虚拟游戏道具。
7. 铲屎动作累计七秒：球球看向盆，手拿铲子来回铲。结束才清空并弹出本次便便/尿团数量；插入排泄时保留剩余清理时间，最终报告含新产生的废物。中途关闭不会清空。
8. 对话支持键盘输入：你最爱谁呀→最爱爸爸妈妈；爸爸妈妈是谁→爸爸是闫江桦，妈妈是张春华；叫爸爸→爸爸；叫妈妈→妈妈；其他→球球不知道。
9. 每年农历九月十八点击祝爸爸生日快乐，其他问题兜底为球球祝爸爸生日快乐；十二月十八妈妈同理。已有固定问题仍按原答案回答。
10. 除夕、春节、元宵、龙抬头、端午、七夕、中秋、重阳、腊八、小年、清明、冬至祝爸爸妈妈节日快乐；除夕与春节说新年快乐。生日优先。农历使用 Android ICU，中国时区，不把闰月重复当生日。
11. 本地永久保存便便、尿团、喂食记录、十秒冷却、下次排泄时间和悬浮位置。停止宠物、退出或进程重启保留；清理只清废物，不重置时间或喂食。重新开启后按时间顺序补播逾期排泄。卸载或清除应用数据会移除记录。

## 验证与复现

- MemoryCheck：保存/重开、排泄中断和重复完成、0/1/2/3/4 次喂食、六小时边界、冷却、离线补播、清理和计时。
- CalendarCheck：真实公历日期与每年农历生日、生日兜底、除夕春节、传统节日、固定家庭问答。测试使用 ICU4J 对同一份 Android 日历代码只替换包名运行。
- preview-check.cjs：电脑预览的记忆、时间窗口、生日和节日与手机逻辑一致。
- ActionCheck / interaction-check.cjs：进食/清理被排泄插入、动作进度恢复、菜单打开仍排泄、忙碌时拖动、反应只触发一次及实际清理计数。
- CompanionCheck / companion-check.cjs：亲密度上限、摸摸冷却边界、每天一次奖励、重开保留及不影响猫砂盆记录。
- assets_check.py：312 张源关键帧的透明通道、行边界与落脚基准；motion-check.cjs 另检查全部 13 套补间网格与 60 个播放相位。
- Android APK 构建、lint、签名校验。未连接安卓真机，悬浮权限、亮屏解锁广播、各手机后台策略和长期运行仍需在手机上确认。

日历核对来源：[香港天文台 2026 年公历与农历日期对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)。清明/冬至以太阳视黄经求对应中国日期，参考 [NOAA 太阳位置算法](https://gml.noaa.gov/grad/solcalc/)。2021 冬至午夜边界按天文台日期修正。

运行 build-apk.ps1 使用项目本地 Gradle 与 Android SDK 构建。运行 checks/run-checks.ps1 重现逻辑检查。电脑预览：python -m http.server 8765 --bind 127.0.0.1 --directory app/src/main/assets/pet-sprites，然后打开 http://127.0.0.1:8765/?preview。页面的“时间与动作检查”仅为预览测试，可以推进时间或选择日期；手机应用始终读取真实时间。
