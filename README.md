# 球球安卓桌面宠物

一只住在手机里的橘色小猫「球球」——能悬浮在所有应用之上陪你聊天、被你照顾，应用内还有它的 3D 小窝和经期日历。Android 8.0 以上可用。

**最新版本：2.3.4**（versionCode 48）

## 功能一览

### 🏠 3D 小窝（应用内）
- 应用主界面是一间 3D 渲染的温暖房间：大落地窗、L 型沙发、圆形茶几、毛绒地毯、落地灯、绿植。
- 球球每次打开应用会**随机出现在 7 个点位**之一：地毯中央、地毯左侧、地毯右侧、茶几上、沙发左座、沙发右座、窗台上。
- 远小近大的透视尺寸，脚下椭圆阴影精确贴合所在平面，真实不悬浮。
- 球球在小窝里仍会播放待机动画。

### 📅 经期日历
- 日历形式记录：例假来的那天点「来了」，走的那天点「走了」。
- 算法学习你的周期，自动**预测下次经期**并在日历上标出。
- 自动标出**排卵期**（排卵日 = 下次月经前 14 天，前 5 后 4 为易孕期）与**安全期**。
- 亮屏问候时，在经期前一天和当天提醒「妈妈明天/今天可能来例假，记得带卫生巾」。
- 经期中再点日期只能标记「走了」，避免误操作。
- 标记「来了」满 7 天仍未「走了」，系统自动把第 7 天记为结束。

### 💬 AI 聊天与记忆
- 悬浮球球支持多轮 AI 聊天，可配置 OpenAI 兼容的接口、模型和自己的 API Key（Key 经 Android Keystore 加密）。
- **长期记忆**：「记住……」「忘掉……」会先复述确认；「我喜欢……」等稳定偏好会询问是否记住。
- **教球球**：用「问题 => 希望的回答」自定义问答，教学答案优先于 AI 自由回答。
- 爸爸妈妈身份、生日、节日等固定规则优先；未配置 AI、断网或超时时，所有桌宠功能和固定回答照常离线工作。
- 聊天与记忆使用 Room 数据库保存。

### 🐱 养成与互动
- **喂食**：猫粮、猫条、巧克力，各有不同反应，带冷却时间。
- **铲屎**：猫砂盆里的便便和尿团积累到点自动产生，可手动清理。
- **陪伴**：摸摸球球会眯眼飘爱心，提升亲密度（最高 100），还有今日心情、相伴天数和称号。
- **动画**：13 套动作（舔毛、趴卧、左右看、走路、奔跑等），待机自动随机切换。
- 球球可在屏幕上任意拖动，靠近边缘会探头。

### 🎂 问候、生日与节日
- 亮屏、解锁时按时间问候「早上/下午/晚上好」。
- 可离线回答今天的公历、农历日期和星期。
- 爸爸（农历九月十八）、妈妈（农历十二月十八）生日祝福与**生日倒计时**。
- 春节、元宵、端午、七夕、中秋、重阳、除夕等传统节日祝福。

## 安装方法

1. 从 [`dist/`](dist/) 目录下载最新安装包 `球球桌面宠物-2.3.4-ai-completion.apk` 并安装。
2. 首次打开，点击「悬浮窗」允许「显示在其他应用上层」。
3. 点击「出门」，球球就会出现在桌面上。
4. 升级时直接覆盖安装即可保留所有养成、聊天和经期记录，无需卸载。

> 部分手机需在系统设置中允许本应用「后台运行」「自启动」，否则球球可能被系统清理。

## 自行构建

环境要求：JDK 17、Android SDK（API 35）。

- **Windows 一键构建**：运行 `build-apk.ps1`，会使用项目自带的 Gradle 构建，并按版本号把 APK 输出到 `dist/`。
- **手动构建**：
  ```bash
  gradle :app:assembleDebug
  ```
  产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 技术栈

- Android（Java），minSdk 26 / targetSdk 35
- AndroidX、Room（聊天与记忆数据库）
- Gradle 构建
- 角色动画使用帧动画 + 网格变形补间；3D 小窝为渲染插画背景
